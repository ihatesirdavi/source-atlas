# Security and privacy

Source Atlas is a local, read-only research evidence viewer. It is not a credential manager or autonomous GitHub engagement tool.

- Never commit real research notes, local directories, user identifiers, access tokens, private screenshots, audit receipts, or installed credentials.
- Use bundled sample-data only for offline tests and public screenshots.
- Treat repository and research metadata as untrusted input; review origins, licenses and context before relying on them.
- Local monitoring requires separately approved directories and an installed, hash-checked audit bundle.
- Offline demo uses no GitHub authentication, network research monitoring or owner data.
- Public source and native Windows release are separate acceptance gates.

Report security issues privately to the repository owner rather than posting sensitive information in an issue.
